# Czech Lab: weekly exercises

The Exercises tab on the Week screen reads this file (run `npm --prefix app run parse` after editing). Everything here was written by Claude, not taken from the curriculum, so every row has `AI` in the Note column. Please check a row and delete `AI` when it is right; a Czech teacher review is still a good idea.

Each week uses only the words and grammar of that week and the weeks before it.

- **Type**: `gap` = fill the gap · `transform` = change the sentence as the brackets say · `dialogue` = reply to the line in Prompt · `scene` = say the English line in Czech (the six scene rows are played in order, like a sentence ladder).
- **Prompt** = what the app shows. A gap is written `___`; words in brackets are hints. Scene rows leave Prompt empty (the app shows the English).
- **Czech** = the answer. Alternatives are separated by " / " (all are accepted), e.g. a male and a female form.
- **English** = the meaning of the whole sentence, shown as a hint.
