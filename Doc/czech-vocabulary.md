# Czech Lab: vocabulary and sentences

The app reads every word and sentence from this file (run `npm --prefix app run parse` after editing).
Edit freely: one row = one item. Keep the three columns.

- **Czech** – exactly as it should be typed. Alternatives are separated by " / " (both are accepted as answers).
- **English** – the meaning shown in drills and review cards.
- **Note** – `AI` = English added by Claude, please check it and delete `AI` when it is right. `★` = chunk: learn whole, grammar comes later.

Weeks 11 and 22-26 are mock and exam weeks with no word lists.
