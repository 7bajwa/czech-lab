# Czech Lab: practice games content

The Games tab reads this file (run `npm --prefix app run parse` after editing). Everything here was written by Claude, not taken from the curriculum, so every row starts with `AI` in the Note column. Please check a row and delete `AI` when it is right; a Czech teacher review is still a good idea.

- Alternatives are separated by " / " (all are accepted).
- **Week** = the curriculum week where this is taught. The games show everything, labelled by week.

**Past (on)** = the masculine past form; the app builds *dělal jsem, dělal jsi, dělal, dělali jsme, dělali jste, dělali*.
**Future**: `budu` = *budu + infinitive* · `-` = perfective verb (its present forms already mean the future) · or six forms separated by " · ".
